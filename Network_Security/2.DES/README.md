# 作業二：DES 對稱加密系統實作 (Simplified/Full)

## 題目描述
請實作 DES 加密演算法。為了作業可行性，建議要求學生實作**標準64-bit 區塊加密**。程式需能處理金鑰生成（Key Schedule）以及 16 輪的疊代運算。

## 輸入格式 (Input Format)
輸入應包含兩個 16 進位（Hexadecimal）字串：
* Key：一個 16 字元的 16 進位字串（代表 64-bit 金鑰，其中 8 bits 為同位檢查碼）。
* Plaintext：一個 16 字元的 16 進位字串（代表 64-bit 明文區塊）。

範例輸入：
```
Key: 133457799BBCDFF1
Plaintext: 0123456789ABCDEF
```

## 輸出格式 (Output Format)
輸出加密過程中的關鍵中間值，以便助教評分：
1. 子金鑰 (Subkeys)：第 1 輪與第 16 輪的子金鑰 ($K_1$ 及 $K_{16}$)。
2. 輪次輸出：第 1 輪加密後的 $L_1$ 與 $R_1$
3. 最終密文 (Ciphertext)：加密完成後的 16 進位字串。

範例輸出：
```
K1: 1A624C394332
L1: 89ABCDEF
R1: BAD018A5
Ciphertext: 85E813540F0AB405
```

## 限制與規範
* 位元操作：嚴禁使用高階加密函式庫（如 `PyCryptodom` 或 `OpenSSL`）。學生需練習使用 `<<`, `>>`, `&`, `|`, `^` 等位元運算子。
* 資料結構：建議使用陣列（Arrays）或清單（Lists）來儲存標準的置換表（IP Table, S-Box, etc.）。
* 程式碼可讀性：需模組化實作，例如將 `S-Box` 轉換寫成一個獨立函式。
