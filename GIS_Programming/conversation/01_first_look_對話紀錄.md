## 使用者

為什麼那麼多缺值

## Claude

實際查了一下三個有缺值的欄位，原因不太一樣：

**`capital`（缺 10,247 筆，約 66%）— 這其實不算「缺值」**
這欄位只有 4 種值：`primary`（國家首都，212 筆）、`admin`（縣市/省級行政中心，3,907 筆）、`minor`（較小的行政中心，1,127 筆）、空白（10,247 筆）。空白代表「這個城市不是任何層級的行政中心」——這是正常且有意義的分類結果，不是資料蒐集時漏掉了什麼。全球 1.5 萬多個城市裡，本來就只有少數是首都或行政中心。

**`population`（缺 1,685 筆，約 11%）— 這是真的缺資料**
進一步查了缺值的分布，發現一個明顯的樣式：
- 幾乎全部（1,680/1,685）集中在 `capital == "admin"`（縣市/省級行政中心）這個類別，`minor` 和空白的城市反而一筆都沒缺。
- 缺值集中在少數幾個國家：菲律賓、斯洛維尼亞、英國、塞爾維亞、拉脫維亞、烏干達等。

這代表資料來源（simplemaps）在收錄這些國家的「行政中心層級」城市時，沒有取得人口數字，但一般城市反而有數字。這是從資料樣式觀察到的推測，不是官方說明——`資料來源說明.md` 沒有寫原因，也沒有欄位定義，所以無法百分之百確定為什麼偏偏是這些國家、這個層級缺得多。

**`admin_name`（缺 191 筆，約 1.2%）**
集中在法羅群島、馬爾地夫、尼泊爾、迦納、烏干達等國，同樣猜測是這些地方缺乏清楚的一級行政區劃分或資料集沒記錄，但一樣無法確認。

另外，`資料來源說明.md` 提到這是 simplemaps 的 **Basic（免費）版**，相對付費完整版通常欄位覆蓋率本來就比較低，這也是整體缺值偏多的合理背景。

## 使用者

那為什麼沒有板橋、南港和金城的人口，這些不是應該很好取得嗎

## Claude

查了完整欄位後發現，這三筆的 `admin_name` 分別是：

| city | admin_name | capital |
|---|---|---|
| Banqiao | **New Taipei**（新北市） | admin |
| Nangan | **Lienchiang**（連江縣／馬祖） | admin |
| Jincheng | **Kinmen**（金門縣） | admin |

也就是說，這三筆不是普通小鎮，而是分別代表整個「新北市」「連江縣」「金門縣」的行政中心（縣市政府所在地）。新北市尤其誇張——它是全臺灣人口最多的直轄市（約 400 萬人，比同一份資料裡高雄的 277 萬還多），連江縣、金門縣的人口也是公開、很好查的統計數字（連江縣約 1.3 萬人、金門縣約 14 萬人）。

所以缺值不是因為「取得困難」，而是這份資料集本身的缺口。

而且這不是臺灣獨有的問題——前面查到「population 缺值幾乎全部集中在 `capital == "admin"` 這個類別」，且集中在菲律賓、英國、斯洛維尼亞等國，臺灣這 3 筆剛好也符合同樣的模式：都是 `capital == "admin"` 的列。比較合理的解釋是：simplemaps 這份 Basic（免費）版資料集，在很多國家的「行政中心」層級城市上系統性地留空了人口欄位——可能是免費版刻意保留一部分資料給付費版，或是他們資料整合流程本身的疏漏。這點沒辦法從資料本身百分之百確認，因為 `資料來源說明.md` 沒寫，需要去查 simplemaps 官方說明或比對付費版才能確定。
