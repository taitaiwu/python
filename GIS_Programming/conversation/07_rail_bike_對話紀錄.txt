❯ pd.concat 是什麼 有什麼用                                                     
  ⎿  ⧉ Selected 1 lines from 07_空間分析與可及性.ipynb in Visual Studio Code

● pd.concat 是 pandas 的函式，用來把好幾個 DataFrame（或
  GeoDataFrame）接成一個。最常見的用法是上下疊起來，增加列數。

  基本用法

  import pandas as pd

  a = pd.DataFrame({"站名": ["彰化", "員林"], "系統": ["TRA", "TRA"]})
  b = pd.DataFrame({"站名": ["彰化"],        "系統": ["THSR"]})

  all_st = pd.concat([a, b], ignore_index=True)

  結果：

     站名   系統
  0  彰化   TRA
  1  員林   TRA
  2  彰化  THSR

  重點

  ┌───────────────────┬──────────────────────────────────────────────────────┐
  │       參數        │                         作用                         │
  ├───────────────────┼──────────────────────────────────────────────────────┤
  │ [a, b, ...]       │ 要放進一個 list，可以一次接很多個                    │
  ├───────────────────┼──────────────────────────────────────────────────────┤
  │ ignore_index=True │ 重新編號 0, 1, 2…。不加的話，原本的 index            │
  │                   │ 會保留，可能出現重複的 0、1                          │
  ├───────────────────┼──────────────────────────────────────────────────────┤
  │ axis=0（預設）    │ 上下接（增加列）                                     │
  ├───────────────────┼──────────────────────────────────────────────────────┤
  │ axis=1            │ 左右接（增加欄），比較少用                           │
  └───────────────────┴──────────────────────────────────────────────────────┘

  - 欄位依欄名對齊。某個表沒有的欄位會補
    NaN，所以接之前最好先把欄名統一（例如都改成 name、system、geometry）。
  - 它只是單純拼在一起，不會依照某個 key 配對資料。要依 key 配對請用
    merge，要依空間位置配對請用 sjoin。

  在這次作業的用途

  臺鐵、高鐵、捷運是分開抓的。各自轉成 GeoDataFrame 之後，用 pd.concat
  合成一張「所有軌道車站」的表，後面的 buffer 和 sjoin_nearest 就只要做一次：

  rail = pd.concat([tra_gdf, thsr_gdf, metro_gdf], ignore_index=True)
  rail = gpd.GeoDataFrame(rail, geometry="geometry", crs=tra_gdf.crs)  # 
  保險起見重新指定 geometry 和 CRS

  接之前要確認這幾個 GeoDataFrame 的 CRS 一致。

● 做法分三步：把 dict 裡每個系統的 JSON 轉成格式一樣的 DataFrame，用 pd.concat
  接成一張表，再轉成 GeoDataFrame 並用 sjoin 篩出彰化縣。

  程式碼

  假設你的 dict 長這樣（沒有的系統放 None）：

  RAIL = {
      "TRA":  TRA,
      "THSR": THSR,
      "TMRT": TMRT,
      "TRTC": ... if CITY in ("Taipei", "NewTaipei") else None,
  }

  接在後面：

  """1. 每個系統各轉成一張欄位相同的 DataFrame，放進 list"""
  frames = []
  for system, data in RAIL.items():
      if data is None:                     # 這個縣市沒有這個系統，跳過
          continue
      # 臺鐵 v3 回傳 dict，車站在 "Stations" 裡；高鐵和捷運 v2 直接回傳 list
      stations = data["Stations"] if isinstance(data, dict) else data

      df = pd.DataFrame({
          "system":     system,
          "station_id": [s["StationID"] for s in stations],
          "name":       [s["StationName"]["Zh_tw"] for s in stations],
          "lon":        [s["StationPosition"]["PositionLon"] for s in stations],
          "lat":        [s["StationPosition"]["PositionLat"] for s in stations],
      })
      frames.append(df)

  """2. concat：把所有系統接成一張表"""
  rail = pd.concat(frames, ignore_index=True)

  """3. 轉成 GeoDataFrame（經緯度 → TWD97 公尺座標）"""
  rail = gpd.GeoDataFrame(
      rail,
      geometry=gpd.points_from_xy(rail["lon"], rail["lat"]),
      crs="EPSG:4326",
  ).to_crs(3826)

  """4. 用鄉鎮市區界判斷車站所在縣市，篩出自己的縣市"""
  town = gpd.read_file(TOWN_SHP)           # 本身就是 EPSG:3826
  rail = gpd.sjoin(rail, town[["COUNTYNAME", "TOWNNAME", "geometry"]],
                   how="left", predicate="within").drop(columns="index_right")
  rail_city = rail[rail["COUNTYNAME"] == CITY_DICT[CITY]].reset_index(drop=True)

  print(rail["system"].value_counts())
  print(f"{CITY_DICT[CITY]} 共 {len(rail_city)} 站")
  print(rail_city.groupby("system").size())

  重點說明

  - 為什麼要先轉成相同的欄位： 三種資料的原始結構不一樣（臺鐵包在 "Stations"
    裡、捷運有 BikeAllowOnHoliday 等欄位），所以先挑出共同需要的欄位，concat
    才會接得整齊。
  - system 欄位： 合併後還能分辨每個站屬於哪個系統。後面處理「共站」也用得到，例
    如彰化站同時有臺鐵和高鐵。
  - 跳過 None： 你在 dict 裡把沒有的系統設成 None，迴圈直接 continue
    就好，concat 不需要另外處理。
  - CRS： 先在 4326 建點再 to_crs(3826)，後面做 buffer 時單位就是公尺。

❯ isinstance 這是什麼                                                           

● isinstance 是 Python 內建的函式，用來檢查某個東西是不是某種型別，回傳 True 或
  False。

  isinstance(物件, 型別)

  例子

  isinstance(3, int)          # True
  isinstance("abc", str)      # True
  isinstance([1, 2], dict)    # False
  isinstance({"a": 1}, dict)  # True

  在你作業裡的用途

  TDX 回傳的資料形狀不一樣：

  ┌───────────────┬──────────┬───────────────────┐
  │     資料      │ 回傳型別 │   車站清單在哪    │
  ├───────────────┼──────────┼───────────────────┤
  │ 臺鐵 v3       │ dict     │ data["Stations"]  │
  ├───────────────┼──────────┼───────────────────┤
  │ 高鐵、捷運 v2 │ list     │ data 本身就是清單 │
  └───────────────┴──────────┴───────────────────┘

  所以那一行：

  stations = data["Stations"] if isinstance(data, dict) else data

  意思是：如果 data 是 dict（臺鐵），就取出裡面的
  "Stations"；不是的話（高鐵、捷運），data 本身就是車站清單，直接用。

  這樣同一個迴圈就能處理三種資料，不用替每個系統各寫一段。

  也可以一次檢查多種型別

  isinstance(x, (int, float))   # x 是整數或小數都回傳 True

  和 type(x) == dict 的差別

  兩個寫法都能用，但一般建議用 isinstance。它也會把「dict 的子類別」當成
  dict（例如 OrderedDict），比較不容易漏判。

❯ agg 是什麼                                                                    
  ⎿  ⧉ Selected 1 lines from 07_rail_bike_access.ipynb in Visual Studio Code

● agg 是 aggregate（彙總）的縮寫。它通常接在 groupby
  後面，對每一組資料做統計或合併，而且可以一次做好幾種。

  拆解你那一行

  rail_city.groupby("系統")["站名"].agg(["count", "、".join])

  ┌─────────────────┬──────────────────────────────────────────────────────┐
  │      步驟       │                         意思                         │
  ├─────────────────┼──────────────────────────────────────────────────────┤
  │ groupby("系統") │ 依「系統」分組：TRA 一組、TRTC 一組…                 │
  ├─────────────────┼──────────────────────────────────────────────────────┤
  │ ["站名"]        │ 每組只看「站名」這一欄                               │
  ├─────────────────┼──────────────────────────────────────────────────────┤
  │ .agg([...])     │ 對每組的站名做 list 裡的每一種處理，每種處理產生一欄 │
  ├─────────────────┼──────────────────────────────────────────────────────┤
  │ "count"         │ 算這組有幾筆                                         │
  ├─────────────────┼──────────────────────────────────────────────────────┤
  │ "、".join       │ 把這組所有站名用「、」串成一個字串                   │
  └─────────────────┴──────────────────────────────────────────────────────┘

  結果大概長這樣：

          count  join
  系統
  NTALRT      9  十四張、秀朗橋、景平、...
  THSR        1  板橋
  TRA        24  福隆、貢寮、雙溪、...
  ...

  agg 裡可以放什麼

  1. 字串名稱： pandas 內建的統計，例如 "count"、"sum"、"mean"、"max"、"min"。
  2. 函式： 任何接收「一組資料」、回傳一個值的函式。"、".join 就是字串的 join
     方法，會把一串站名接起來。

  "、".join(["板橋", "新埔", "府中"])   # → "板橋、新埔、府中"

  和直接呼叫的差別

  只要一種統計時可以直接寫：

  rail_city.groupby("系統")["站名"].count()

  要同時算好幾種時，就用 agg 一次完成，不必分開寫再合併。

  進階：自訂欄名

  rail_city.groupby("系統")["站名"].agg(站數="count", 站名列表="、".join)

  這樣輸出的欄名會是「站數」、「站名列表」，比 count、join 好讀。

● 問題出在你檢查的欄位：站名_left 應該改成 站名_right。

  為什麼

  sjoin_nearest(..., how="left", max_distance=500) 的結果是：

  ┌────────────┬─────────────────────────┬──────────────────────────────────┐
  │    欄位    │        來自哪裡         │        500 m 內沒有站點時        │
  ├────────────┼─────────────────────────┼──────────────────────────────────┤
  │ 站名_left  │ 左邊：車站自己的站名    │ 一定有值，how="left"             │
  │            │                         │ 會保留每個車站                   │
  ├────────────┼─────────────────────────┼──────────────────────────────────┤
  │ 站名_right │ 右邊：YouBike           │ 空值（NaN）                      │
  │            │ 站點的站名              │                                  │
  └────────────┴─────────────────────────┴──────────────────────────────────┘

  2. 站距短： 兩站相距不到 1000 公尺時，兩個 500 公尺環域就會部分重疊。新北有
     70% 的車站（81 筆），最近的另一站在 1000 公尺內，捷運和輕軌沿線特別密集。
