# 資料來源說明

## worldcities.csv

- **來源：** simplemaps World Cities Database（Basic 版）
- **授權：** Creative Commons Attribution 4.0（CC BY 4.0），使用時須標示來源 simplemaps.com
- **版本：** 教師於 2025 年取得，確切的資料年份不明
- **規模：** 15,493 筆，11 個欄位

本檔案**不提供欄位定義**。各欄位的意義請實際檢查資料，並查閱資料來源的官方說明，不要只從欄位名稱猜測。

## `Taiwan_boundaries/Town/Taiwan_town.shp`：鄉鎮市區界

- **來源：** 內政部鄉鎮市區界，2019 年 6 月版（中繼資料記載為 `TOWN_MOI_1080617`），沿用上學期課程資料。
- **CRS：** EPSG:3826（TWD97 二度分帶，單位公尺）。
- **範圍：** 19 個縣市、352 個鄉鎮市區。**沒有澎湖縣、金門縣、連江縣。**
- **欄位：** `TOWNCODE`（鄉鎮市區代碼）、`COUNTYNAME`、`TOWNNAME`、`FULLNAME` 等。
- **`CENSUS`：** 檔案沒有說明來源與年份。臺北市加總為 2,650,154 人，約為 2019 年前後的戶籍人口；使用前請自行查證。
- Shapefile 由多個同名檔案組成（`.shp`、`.shx`、`.dbf`、`.prj`、`.cpg` 等），**整個資料夾一起上傳**。

## `tdx_station_20261012/`：TDX 公共自行車站點（備援快照）

- **來源：** 運輸資料流通服務平臺（TDX）`/v2/Bike/Station/City/{City}`，由教師帳號於 **2026-10-12 15:05–15:10（臺灣時間）** 取得，未經修改。
- **用途：** TDX 會員審核還沒通過時，代替自己的 API 呼叫。作業請盡量用自己的金鑰取得資料。
- **檔案：** `station_{縣市代碼}.json`，共 15 個縣市（這支 API 接受的全部縣市）。
- **欄位：** `StationUID`、`StationName.Zh_tw`、`StationPosition.PositionLon`（經度）、`StationPosition.PositionLat`（緯度）、`ServiceType`（1 = YouBike 1.0、2 = YouBike 2.0、3 = Moovo）等。座標為經緯度（EPSG:4326）。
- 彰化縣、雲林縣是 Moovo，沒有 `BikesCapacity` 欄位。
