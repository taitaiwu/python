# 富翁分配財產

某富翁有10份資產，他依其價值由低至高編號為1到10。今天他要這10份資產公平分配給其3個子女，使得每子女分到的資產編號總額是相同的，其中一份他要捐作公益。且最大的子女要能取得某編號資產。

**輸入說明：**
* 在` Enter 2 values separated by spaces: ` 提示下, user 輸入2個數字，分別表示公益資產編號及最大的子女特定編號資產

**輸出說明：**
* 將最大的子女獲得之資產, 由小至大列出，每編號以空白隔開。若無分配方法映出`-1`。若有多組解則取由小至大所能組成之最小數值之三個數字. 若三個數字為1、4、10，則組成之數值為1410。若三個數字為1、5、9，則組成之數值為159，因此印出`1 5 9`

**範例輸入一：**
```
Enter 2 values separated by spaces: 4 3 
```

**範例輸出一：**
```
3 5 9
```
