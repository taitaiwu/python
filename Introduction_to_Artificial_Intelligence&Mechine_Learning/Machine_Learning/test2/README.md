# 嫌惡設施處理

我們生活周遭環境可能存在一些嫌惡設施，我們可依程度給於一整數值。我們將此資訊用excel `.csv`檔來儲存，將此整數值，存在矩陣相對位置，現某一建商要要在此片土地上建設下列2種基地樣式中，選擇其中一種基地。		
```
◼ ◼ ◼ ⊠ ⊠ ⊠
◼ ◼ ◼ ⊠ ⊠ ⊠
◼ ⊠ ⊠ ◼ ◼ ◼
◼ ⊠ ⊠ ◼ ◼ ◼
◼ ⊠ ⊠ ◼ ◼ ◼
◼ ◼ ◼ ◼ ◼ ◼
◼ ◼ ◼ ◼ ◼ ◼
```

嫌惡設施若在此基地內有其整數值處理成本，若在鄰近區域(上、下、左、右、左上、左下、右上、右下)則有 $\frac{1}{2}\times\text{整數值}$ 的處理成本，現要以程式幫建商算出要用哪一種樣式的基地，蓋在何處才能使處理成本最少。

**輸入說明：**
* 從 [1.csv](1.csv) 讀取一 $m \times m$ 矩陣資料, 第一列為 $m$ 之值。接下來 $m$ 列則是基地開發成本矩陣之值

**輸出說明：**
* 第一列輸出最小處理成本基地之左上角區塊位置 `(x,y)` 中 `x` 為列之值， `y` 為行之值；第二列輸出最小處理成本基地之右下角區塊位置 `(x,y)` 中 `x` 、 `y` 之值，中間以空白隔開。
* 其中整片土地座標，左上角區塊為 `(0, 0)`，右下角區塊為 `(m-1,m-1)`。
* 若有兩個基地有相同開發成本，則取底部最靠下方區塊；若還是有相同開發成本，則取基地最靠右方之區塊；若此時還有相同開發成本，則取下方區塊最多之基地。

** 範例輸入1：**
```
4
7,1,7,4
4,4,4,4
1,2,4,1
1,0,1,1
```

**範例輸出1：**
```
2 1
3 3
```

**範例輸入2：**
```
4
2,1,0,0
2,0,0,0
2,2,0,1
1,2,2,2
```

**範例輸出2：**
```
0 2
2 3
```
